# Contributors

AmigaPKG is maintained by the community - every entry in `packages/` can be
added or corrected by anyone via pull request. This file thanks everyone who
has: contributors add themselves in their PR (one line, newest first).

- **DJBase** (amigaworld.de) - hosts the WookieChat and Lumi archives and the
  Fallout 1/2 CE 68k ports; early tester whose reports shaped the 0.4/0.5
  clients; the LumiPass GUI inspired the amipkg MUI front-end redesign.
- **evil4dmin** - first external package PR (`mcamigaxpe`).
- The **0.4/0.5 tester crew** on Discord and EAB - crash traces from real
  A4000/Vampire/OS4.1 machines drove a dozen releases in two days.
- **Thomas Luebker** - maintainer, trust root, keeper of the signing key.
